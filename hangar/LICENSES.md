# Hangar renders: licences / Hangar görselleri: lisanslar

Rendered in Unreal Engine 5.8.4 (Movie Render Queue, Lumen) from the project's dev maps `L_Hangar_Verdant` (the Forest
Fortress hangar, files `*_ff_*`) and `L_Hangar_Ochre` (the Desert Tigers hangar, files `*_dt_*`).
This folder holds rendered images only (WebP/PNG/AVIF stills and frame sequences). No 3D model,
texture, material or other source asset of any pack is included or redistributed here.

Dosya adları: `ff` = Forest Fortress / Orman Hisarı (savunan taraf, orman hangarı), `dt` = Desert Tigers / Çöl Kaplanları
(saldıran taraf, çöl hangarı). Mech adları: Wrecker / Yıkıcı (dosya `breaker`), Fortress / Kale (`fortress`), Carrier / Taşıyıcı
(`courier`), Shade / Gölge (`shade`).

Bu klasörde yalnızca Unreal Engine 5.8.4 ile alınmış render görüntüleri (WebP/PNG/AVIF kareler ve durağan görseller) vardır.
Hiçbir paketin 3B modeli, dokusu, materyali ya da başka bir kaynak dosyası burada yer almaz ve yeniden dağıtılmaz.

## English

### File names
- `ff` = Forest Fortress (FF, defenders, the forest hangar); `dt` = Desert Tigers (DT, attackers, the desert hangar).
- `<file>_<ff|dt>_001..120.webp`: 120-frame 360 degree turntable loops; `<file>` is the model id: `breaker` = Wrecker,
  `fortress` = Fortress, `courier` = Carrier, `shade` = Shade. `stills/<file>_poster.png`, `stills/<ff|dt>_empty.png`.

  the Desert Fortress site.
